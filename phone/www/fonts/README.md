# Fonts

The brand's two fonts, bundled so the staff app looks right with no internet
(UPGRADE.md T2.20). The same files the POS uses, as next/font downloads them,
Latin subset only.

- `inter-latin.woff2`: Inter, by Rasmus Andersson. SIL Open Font License 1.1.
- `bree-serif-latin.woff2`: Bree Serif, by TypeTogether. SIL Open Font License 1.1.

The licence: https://openfontlicense.org/open-font-license-official-text/
