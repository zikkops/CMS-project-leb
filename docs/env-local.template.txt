# ── 2. Firebase server (Admin SDK) ──────────────────────────────────────────
# Console → ⚙ Project settings → Service accounts → Generate new private key.
# A JSON file downloads. Base64 the WHOLE file and paste the result on one line:
#
#   PowerShell:
#     [Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\Downloads\FILE.json")) | Set-Clipboard
#
# Base64 rather than the raw JSON because the private key is a multi-line PEM —
# pasting it raw is the most common way this setup breaks, and the error you
# get ("Invalid PEM formatted message") doesn't tell you that's why.
#
# Delete the downloaded JSON afterwards. Treat it like a database root password.

FIREBASE_SERVICE_ACCOUNT=

# ── Scheduled jobs ───────────────────────────────────────────────────────────
# Shared secret for Vercel Cron. Vercel sends it as `Authorization: Bearer
# <value>` on every scheduled request, and /api/admin/loyalty/reset compares it
# before doing anything.
#
# That route zeroes every customer's points balance, so the handler FAILS
# CLOSED when this is unset — it returns 503 rather than running. An unset
# secret must never mean "anyone may call this", because unset is exactly the
# state nobody is watching for.
#
# Any long random string. Set the same value in the Vercel project settings.
